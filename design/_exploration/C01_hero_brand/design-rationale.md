## 逐张点评

### A. 纯黑宇宙 + 极光紫光球（最推荐之一）

**做对的事**：
- 纯黑深空 + 紫光球的视觉对位，呼应"Fathom 暗色宇宙"和"极光紫"两个 locked 决策
- 玻璃面板有可见的 1px 紫色描边
- 中文"映话"在玻璃面板上**渲染清晰**（不是字符画）
- 极简、神秘、留白

**问题**：
- 紫光球稍偏实心，缺少"能量/扩散"感
- 玻璃面板位置略偏右下，构图可以更平衡

**复用**：
- ✅ 极光紫光球 = 映话 logo 的隐喻
- ✅ 玻璃面板承载文字 = 设计系统的核心
- ✅ 整体氛围 = 映话所有 hero 资产的底色

### B. 液态金属紫

**做对的事**：
- 极光紫金属液体的物质感 + 黑色镜面反射
- 顶部"映话"玻璃带 + 数字泡影感
- 商业感最强

**问题**：
- "映话" 文字有微小气泡模糊
- 紫色 splash 占据构图主体，弱化了"对话"隐喻
- 整体偏"产品 / 物质"调，偏离"对话 / 实时"产品语义

**复用**：
- ⚠️ 元素可拆解：液体 splash 可作"动效"或"特效"，但不当主 hero
- ❌ 不直接复用整张图

### C. 极光紫光带横切（最弱）

**做对的事**：
- 紫色光带横切 = 极简几何感

**问题**：
- 顶部被生成了 macOS 顶 bar（Apple logo / WiFi / 10:00 AM）—— prompt 误读
- 转录框文字"正在实时转录 - 语音输入正在处理中"重复 3 遍——把"sample"字面化了
- 底部出现了一个空的暗色窗口
- 整体是"macOS 截图"不是"hero 图"

**复用**：
- ❌ 整张图不直接复用
- 📌 教训：prompt 里避免触发"macOS screenshot"或"UI mockup"这种倾向的关键词

### D. 紫粒子漩涡

**做对的事**：
- 紫粒子漩涡 + 中心"映"字玻璃球 = 极强视觉冲击
- 极光紫渐变层次丰富
- 数字"映"单独呈现在玻璃球中 = 干净

**问题**：
- 顶部被生成了 macOS 顶 bar（电池 / WiFi / 21:47 UTC）
- 周围被生成了 dashboard 元素（Overview/Analytics/Data Flow/Settings tabs, Bandwidth/Latency 数字, Connect 按钮）—— prompt 里没有但模型自己补了
- "映话"被截断成"映"，是"映"单独呈现的合理化
- 整体偏 dashboard 而不是 hero

**复用**：
- ⚠️ 漩涡单独可作"动效研究"或"产品内过场动画"
- 📌 教训：避免 prompt 触发"data visualization"或"dashboard"关键词

## 关键发现

1. **A 和 E 是两条最清晰的方向**：
   - A = 极简宇宙 / 紫光球
   - E = 暗色城市 / 紫霓虹
   - 这两条可以并存：A 用于"产品介绍 / 内部 hero"，E 用于"营销 / 落地页"

2. **C 和 D 跑偏说明 prompt 工程需要更精细**：
   - 避免"macOS / dashboard / data flow" 这类容易触发 UI 截图的关键词
   - 在 master prompt block 里加 "no UI elements, no dashboards, no control bars"
   - C2 时改进 master block

3. **B 是"商业感 vs 对话感"的分歧点**：
   - 用户原话："我们再说主要功能"——映话是**对话 / 实时**产品，不是物质 / 工艺
   - B 偏物质 / 工艺，**不太适合映话**
   - 但液体飞溅的动效可拆解到 motion study（C14）

4. **中文渲染全部清晰**——matrix 在中文 UI 渲染上**表现优秀**，可以作为映话的主力工具（验证 B1 工具矩阵假设）
