映話 · ローカル優先

録音、文字起こし、AI 要約はすべてあなたの Mac に保存されます。アプリをアンインストールすれば完全に削除。Apple Silicon 最適化で文字起こし遅延 200 ms 未満。

Otter.ai · クラウド中心

Fireflies.ai · 协作型

Zoom AI Companion · プラットフォーム固定

Zoom 会議でのみ利用可能、Zoom 以外のプラットフォームでは使えません。AI 要約を解放するには有料 Zoom アカウントが必要。

私たちがなぜ違うか

3 つの原則で、映話は別の選択肢になります。

ローカル優先

録音、テキスト、ベクトルインデックスはすべてあなたの Mac 上に。オフラインでも録音と文字起こしは継続でき、AI 要約時のみネットワークが必要です。

BYOK

自分の AI Key を持込めます。Anthropic / OpenAI / Ollama を選択可能、token 費用はあなたの AI アカウントに直接請求され、映話は中間マージンを取りません。

オープンソースクライアント

核となる文字起こしと暗号化モジュールは GitHub でオープンソース公開、誰でも監査・フォーク・私たちが密かにデータを送信していないかの検証が可能。
