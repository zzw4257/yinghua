システム要件

macOS 26 Tahoe 以降

SwiftUI 6 + AppKit インターオペの新 API が必要。macOS 15 以前はサポート対象外。

Apple Silicon 推奨 · Intel 互換

M1 / M2 / M3 / M4 でフル性能。Intel Mac でも動作しますが、文字起こし速度は約 5 倍低下します。

約 2 GB のディスク容量

アプリ本体は約 200 MB、初回起動時に Whisper 日本語モデル約 1.5 GB をダウンロード。モデル保存先は手動指定可能。

マイク + 画面収録の権限

初回起動時に権限付与を案内します。システム設定 → プライバシーとセキュリティ でいつでも調整可能。

既知の問題

  • Zoom ウェブ版（zoom.us/wc）は Chrome 118 より前のバージョンではシステム音声キャプチャ不可 — Chrome をアップデートしてください。
  • 一部の外付け USB マイク（特定モデル）は M1 Mac で初回接続時に映話の再起動が必要。
  • ローカル Whisper モデルは大ファイル（4 GB 超）の文字起こし時に RAM 使用量が大きい（16 GB 以上のメモリ推奨）。
  • macOS 15 Sequoia は現在未対応 — SwiftUI 6 の新 API を使用しているため、下位互換はありません。
インストール手順

3 ステップで使い始められます。

01

ダウンロード & ドラッグ

Mac App Store または GitHub Releases から映話をダウンロードし、Applications フォルダにドラッグ。

02

マイク & 画面収録の許可

初回起動時にガイドに従って許可。システム設定 → プライバシーとセキュリティ でいつでも変更可能。

03

（任意）BYOK 設定

Anthropic または OpenAI の API Key を貼り付けると、すぐに AI 要約が使えます。Key なしでも文字起こしは利用可能です。
