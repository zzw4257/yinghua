映話よくある質問。

最もよく寄せられる 10 の質問 · クリックして完全な回答を展開。

ローカル優先。映話の録音、文字起こし、AI 要約はすべてあなたの Mac 上で完結し、クラウドサーバーには一切アップロードされません。

唯一 Mac の外に出うるデータは AI 要約リクエスト時のテキスト断片です — しかもこれはあなたが能動的に BYOK（Anthropic / OpenAI / Ollama）を有効化したときのみ発生します。テキスト断片は TLS 1.3 暗号化チャネルで送信され、呼び出し記録はあなたの AI アカウントのバックエンドに残り、映話のバックエンドには入りません。

ネットワークがない環境では：録音、ローカル文字起こし、話者分離はすべて動作し続け、AI 要約のみ後から追加できます。

安全です。あなたが提供する API Key は常に macOS Keychain（システムレベル暗号化ストレージ）に保存され、映話のプロセスはユーザー権限で Keychain にアクセスします。アプリのサンドボックス外のプロセスは読み取れません。

Key は以下の場所には一切現れません：

  • すべてのログファイル（クラッシュログを含む）
  • 書き出した Markdown / SRT / JSON
  • クラッシュレポート
  • すべてのネットワークリクエストの header / body

設定 → 認証情報 でいつでも Key の確認、ローテーション、削除が可能です。

デフォルトではされません。すべての録音（システム音声 + マイク）は ~/Library/Application Support/Yinghua/recordings/ に保存され、あなたの Mac 上の映話プロセスのみがアクセス可能です。

唯一の例外：設定 → 文字起こし → エンジン で「クラウド文字起こし」を選択した場合、録音断片は TLS 1.3 暗号化チャネルでクラウド文字起こしサービスへ送信されます（処理完了後すぐに削除）。このオプションはデフォルトで無効で、Mac の性能がローカル文字起こしに不十分な場合にのみ推奨されます。

完全なデータフローと権限境界については セキュリティアーキテクチャ をご覧ください。

何にも影響しません。映話のコア機能はすべてローカルで動作します：

  • システム音声 + マイク録音 → 継続動作、ローカルへ書き込み
  • ローカル文字起こし（macOS 26 SpeechAnalyzer）→ 継続動作、テキスト即時表示
  • 話者分離 → 継続動作
  • AI 要約 → 「ネットワーク待ち」とマークされ、復帰後に自動リトライ

飛行機、地下鉄、ホテル WiFi が不安定な場所でも安心して映話をお使いいただけます。ネットワーク復帰後に AI 要約を追加生成できます。

映話は特定プラットフォームの API ではなくシステム音声（再生中のすべての音声）をキャプチャするため、すべての会議プラットフォームに対応します：

  • Zoom（デスクトップ版 / Web 版）
  • Microsoft Teams（デスクトップ版 / Web 版）
  • Google Meet（Web 版、Chrome 拡張で最適化）
  • Cisco Webex
  • Skype、Slack Huddles、Discord 音声
  • FaceTime、WhatsApp、Telegram 通話
  • macOS で音声を再生するすべての会議ソフト

ご利用のプラットフォームがリストにない場合でも、Mac のスピーカー / ヘッドホンから音声が出ていればほぼ確実に動作します。

AI 要約の品質は使用するモデルと会議内容に依存します。映話側はいかなる後処理も行わず、文字起こしテキストを 4 段構成（重要な瞬間、決定、ToDo、課題）で AI に渡すだけです。

実測データ（100 名以上の早期ユーザー、2026 年 7 月アンケート）：

  • Anthropic Claude Sonnet 4.5：ユーザー満足度 4.6 / 5、重要な瞬間の再現率約 87%
  • OpenAI GPT-4o：ユーザー満足度 4.4 / 5、ToDo 認識に優れる
  • ローカル Ollama（Qwen 2.5 7B）：ユーザー満足度 3.6 / 5、速度が制約

AI 要約は「二次確認が必要なドラフト」として扱い、権威ある記録としないでください。映話は常にオリジナルの文字起こしを保持しており、いつでも見返すことができます。

ハードな制限はありません。映話は 48 kHz / 16-bit PCM で録音し、ステレオ 1 時間あたり約 690 MB です。

16 GB / 512 GB MacBook Pro での実測値：

  • 連続 8 時間録音でフレーム落ちなし（macOS Core Audio 内部バッファの制約による）
  • ディスク容量が許す限り時間無制限
  • デフォルト 30 日で自動削除、設定 → ストレージ で 7 / 30 / 90 / 365 日 / 永続に調整可能

録音中はいつでも一時停止、再開、重要な段落へのマーカー付与が可能です。

macOS 26 Tahoe 以上 · Apple Silicon（M1 / M2 / M3 / M4）または Intel 第 14 世代以上。

具体的な要件：

  • macOS 26.0 以降（macOS 26 SpeechAnalyzer 必須）
  • Apple Silicon M1 以降（推奨）/ Intel Core i7 第 14 世代以降
  • 8 GB メモリ（推奨 16 GB、ローカル Ollama 7B は 16 GB+ 必要）
  • 5 GB 利用可能ディスク容量（アプリ本体）
  • 画面収録の許可（システム音声キャプチャ用）
  • マイクの許可（任意、あなたの声を録音する場合のみ）

Intel Mac でも動作しますが、文字起こし速度は M1 の約 1/3 です。Mac が要件を満たさない場合は v0.1.0 以前の Web 体験版（アーカイブ済み）をお使いください。

最大 8 名。声紋特徴に基づくローカル分離モデルで、認識精度は以下のとおり：

  • 2-4 名：97% ラベル安定
  • 5-6 名：91% ラベル安定
  • 7-8 名：82% ラベル安定
  • 8 名超：汎用ラベルのみ表示、手動編集を推奨

すべてのラベルは文字起こしビューで手動修正可能です — テキストを選択して正しい話者名を入力すると、映話が修正を学習し、類似の声紋には自動でマッチします。

8 名を超えるシーン（大型円卓、ワークショップ、講義）では手動の議事録または分割録音を推奨します。
