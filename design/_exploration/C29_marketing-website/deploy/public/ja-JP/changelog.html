v0.1.0 · 2026-08-23

映話 v0.1.0 · 公開ベータ。

2026 年 8 月 23 日リリース · 100 名以上の早期ユーザー · 14 項目の独立監査に通過。

リリース

新機能

  • +
    システムレベルの録音。macOS 26 の ScreenCaptureKit でシステム音声をキャプチャし、AVAudioEngine でマイク入力を取り込みます。サンプリングレート 48 kHz / 16-bit、ドライバ不要、依存ゼロ。
  • +
    リアルタイム文字起こし。macOS 26 SpeechAnalyzer エンジンを内蔵、言語は自動検出、中国語・英語・日本語の 3 言語をデフォルトで有効化、文節遅延 200 ms 未満。
  • +
    AI 要約 · 4 段構成。重要な瞬間、決定事項、ToDo、未解決の課題。会議終了直後に Markdown と JSON の両形式で生成。
  • +
    高度な BYOK。Anthropic Claude Sonnet / OpenAI GPT-4o / ローカル Ollama（Qwen 2.5 / Llama 3.1）に対応、Key は macOS Keychain に保存され、本機を離れません。
  • +
    Chrome 拡張。Google Meet、Zoom Web、Microsoft Teams の Web 版を自動認識して文字起こし。拡張機能自体には一切データを保存しません。
  • +
    14 項目の独立監査。ローカル文字起こし、暗号化モジュール、BYOK 呼び出しチェーン、macOS 権限境界、HTTPS 強制、クラッシュレポートのデフォルト無効化など、監査可能な 14 項目すべてが PASS。
  • +
    話者分離。声紋特徴に基づくローカル分離モデル、1 会議あたり最大 8 名対応、ラベルは手動で修正可能。
修正

主要な修正

  • ×
    BYOK 失敗時にモック要約へフォールバックしていた問題。初期テスト版ではネットワークが不安定な際、モック内容を本物の要約として返していました。現在は BYOK 失敗時に「AI 要約は一時的に利用できません」と明示し、いかなる架空の内容も返しません。
  • ×
    録音停止後 30 秒以内に Keychain がロックされると文字起こしが失われる問題。文字起こしワーカープロセスを launchd 配下に移し、ユーザーログインセッションに依存しない構成に変更。
  • ×
    中国語長会議（2 時間超）で声紋ドリフトが発生。声紋モデルに 90 秒スライディングウィンドウによる再アンカーを導入し、8 名会議のドリフト率を 12% から 1.4% に低減。
  • ×
    SRT 書き出しタイムコードの ±500 ms オフセット。VAD セグメント末尾の無音が文境界と一致していなかったのが原因。句読点での区切りに変更しました。
既知

既知の問題

  • カレンダーイベントが現地長形式ではなく曜日名（"Mon" / "火"）を表示。zh_CN / en_US へ切り替えても更新されません。v0.1.1 で修正予定。
  • メニューバー app 名が「映話」ではなく「yinghua」と表示される。Bundle ID のリネームはコード署名に関わるため、v0.1.1 で同期更新。
  • Stage Manager 起動時に Dock アイコンの並びが時折圧縮される。見た目のレイアウトのみで機能には影響なし。
  • Chrome 拡張が Manifest V3 厳格モード下でシステム音声を取得できないことがある。Web 側で先にマイク権限を許可する必要があります。v0.1.2 で対応予定。
  • ローカル Ollama モデル（Qwen 2.5 7B）で M1 要約に約 18 秒。より小さい 3B モデルか外付け GPU の使用を推奨します。
