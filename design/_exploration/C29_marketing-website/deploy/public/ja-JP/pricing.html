よくあるご質問

まだ疑問がありますか？

無料版では毎月 5 回まで会議を文字起こしできます（1 回あたり最大 60 分）、すべてのデータはご自身の Mac に完全に保存されます。リアルタイム文字起こし、話者分離、Markdown エクスポートなど、すべてのコア文字起こし機能をご利用いただけます。AI 要約、デバイス間同期、ブラウザ拡張は Pro サブスクリプションが必要です。

BYOK = Bring Your Own Key（自分の API Key を使う）。ご自身の Anthropic Claude または OpenAI の API Key を提供していただき、映話はそれを使って AI 要約を呼び出します。Key は macOS Keychain に保存され、私たちのサーバーには一切アップロードされません。これにはいくつかの利点があります：呼び出し記録はご自身の OpenAI / Anthropic アカウントに残るため、コンプライアンスと課金がより明確になり、映話はあなたのデータに触れません。

デフォルトではアップロードされません。映話のすべての録音、文字起こしテキスト、ベクトルインデックスはご自身の Mac のローカル（SQLite ファイルとファイルシステム）に保存されます。データがデバイスを離れるのは次のケースのみです：
1)「クラウド文字起こし」を能動的に選んだ場合（従量課金制、オプション）；
2) BYOK を使って AI API を呼び出した場合（ご自身のアカウントの token 課金）；
3) iCloud エンドツーエンド暗号化同期を有効にした場合（E2EE、映話は復号不可）。

映話は macOS 26 Tahoe 以降が必要です（SwiftUI 6 と AppKit インターオペの新 API を使用しているため）。Apple Silicon（M1 / M2 / M3 / M4）と Intel Mac の両方をサポートしますが、Apple Silicon のほうがパフォーマンスが大幅に優れます。macOS 15 以前はサポート対象外です。

macOS App Store 経由で購入されたサブスクリプションは、App Store → アカウント設定から直接返金申请を行えます（Apple ポリシー）。公式サイトから購入されたサブスクリプションは、billing@yinghua.app までメールでご連絡いただければ、14 日以内であれば理由無 Refund で対応します。
