基盤と公開ベータ

ローカル文字起こし、AI 要約、BYOK、Chrome 拡張、独立監査 — すべて 2026 年 8 月 23 日に公開。

  • macOS 26 Tahoe クライアント · Apple Silicon ネイティブ
  • iOS 26 クライアント（基本版） · iPhone で文字起こしと閲覧
  • Chrome 拡張 · Google Meet / Zoom Web / Teams Web 対応
  • BYOK 統合 · Anthropic / OpenAI / Ollama
  • 5 項目の独立監査 · C06 / C07 / C08 / C09 + ビジネスコンプライアンス
  • 話者分離 · 声紋特徴ローカルモデル、最大 8 名
v0.2.0 2026 Q4
進行中

完成とチーム协作

v0.1.0 の隅々まで磨き上げ、不足していたライトモード、完全な iOS、协作機能を補完します。

  • ライトモード · ガラス面とハイライト色を完全最適化、prefers-color-scheme 自動切替
  • iOS 26 完全版 · SwiftUI でネイティブ書き直し、macOS とローカル DB 共有
  • Apple Watch コンパニオン · 会議中、手首でワンタップミュート、残り時間、話者
  • チーム tier · 共有ワークスペース、SSO（Okta / Azure AD）、監査ログ
  • Settings 完全版 · 設定パネルを再設計、フルキーボードアクセス対応
  • SOC 2 Type II 着手 · 12 ヶ月の観察期間開始
v1.0 2027 Q3
計画中

クロスプラットフォーム GA とオープンエコシステム

正式版（GA）リリース、主要デスクトッププラットフォームをカバー、プラグイン API 公開でコミュニティが映話を拡張可能に。

  • Windows 11 クライアント · ARM64 ネイティブ、Windows Studio Effects 統合
  • Linux クライアント · Ubuntu 24.04 LTS / Fedora 41 優先、Wayland ネイティブ
  • 协作 · 複数人で同じ会議の文字起こしをリアルタイム共有、コメントとハイライト
  • プラグイン API · コミュニティがカスタム AI prompt / データ出力形式を注入可能に
  • SOC 2 Type II レポート · 12 ヶ月の観察期間を完了し、レポート公開
