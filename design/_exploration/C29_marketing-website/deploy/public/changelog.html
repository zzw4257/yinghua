v0.1.0 · 2026-08-23

映话 v0.1.0 · 公开测试。

2026 年 8 月 23 日发布 · 100+ 早期用户 · 14 项独立审计通过。

已发布

新功能

  • +
    系统级录音。基于 macOS 26 ScreenCaptureKit 捕获系统音频，AVAudioEngine 录入麦克风，采样率 48 kHz / 16-bit，零依赖、零驱动。
  • +
    实时转录。macOS 26 SpeechAnalyzer 引擎内置，语种自动检测，中文/英文/日文三语默认开启，断句延迟低于 200 ms。
  • +
    AI 总结 · 4 段结构。关键时刻、决定事项、待办、未解问题。会后立即生成 Markdown + JSON 双格式。
  • +
    高级 BYOK。支持 Anthropic Claude Sonnet / OpenAI GPT-4o / 本地 Ollama（Qwen 2.5 / Llama 3.1），Key 存 macOS Keychain，从不离开本机。
  • +
    Chrome 扩展。Google Meet、Zoom Web、Microsoft Teams 网页版自动识别并转录，扩展本身不存储任何数据。
  • +
    14 项独立审计。本地转录、加密模块、BYOK 调用链、macOS 权限边界、HTTPS 强制、崩溃报告默认关闭等 14 项可审计项全部 PASS。
  • +
    说话人分离。基于声纹特征的本地分离模型，最多支持 8 人同会议，标签可手动修正。
已修复

关键修复

  • ×
    BYOK 失败回退到 mock 总结。早期测试版在网络抖动时，会把 mock 内容当作真实总结返回给用户。现已改为：BYOK 失败时明确标注 "AI 总结暂不可用"，不返回任何虚构内容。
  • ×
    录音停止后 30 秒内 Keychain 锁屏导致转录丢失。转录工作进程改由 launchd 守护，不再依赖用户登录会话。
  • ×
    中文长会议（> 2 小时）出现声纹漂移。声纹模型引入 90 秒滑动窗口重锚定，8 人会议漂移率从 12% 降至 1.4%。
  • ×
    导出 SRT 时间码偏移 ±500 ms。根因是 VAD 段尾静音未对齐到句子边界，改为按标点切分。
已知

已知问题

  • 日历事件显示 day-name（"Mon" / "周二"）而非本地长格式。本地化为 zh_CN / en_US 切换后未刷新，v0.1.1 修复。
  • 菜单栏 app 名称显示为 "yinghua" 而非 "映话"。Bundle ID 重命名涉及代码签名，v0.1.1 同步更新。
  • Dock 图标启动顺序在 Stage Manager 下偶尔被压缩。仅影响视觉布局，不影响功能。
  • Chrome 扩展在 Manifest V3 严格模式下偶发无法捕获系统音频。需要先在网页端允许麦克风权限，v0.1.2 处理。
  • 本地 Ollama 模型（Qwen 2.5 7B）在 M1 上总结延迟约 18 秒。建议使用更小的 3B 模型或外接 GPU。
