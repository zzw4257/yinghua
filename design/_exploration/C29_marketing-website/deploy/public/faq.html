10 个最常被问到的问题 · 点击展开查看完整回答。

本地优先。映话的录音、转录、AI 总结全部在你的 Mac 上完成，不上传到任何云端服务器。

唯一可能"出 Mac"的数据是 AI 总结请求的文本片段 — 而且这只在你主动启用 BYOK（Anthropic / OpenAI / Ollama）时才会发生。文本片段通过 TLS 1.3 加密通道发送，调用记录在你的 AI 账户后台，不进入映话的任何后端。

无网络时：录音、本地转录、说话人分离都能正常工作，只是无法生成 AI 总结。

安全。你提供的 API Key 始终存储在 macOS Keychain（系统级加密存储），映话进程以用户态访问 Keychain，应用沙盒外的进程无法读取。

Key 不会出现在：

  • 任何日志文件（包括崩溃日志）
  • 导出的 Markdown / SRT / JSON
  • 崩溃报告
  • 任何网络请求的 header / body

你可以随时在 设置 → 凭据 中查看、轮换、删除你的 API Key。

默认情况下不会。所有录音（系统音频 + 麦克风）都存放在 ~/Library/Application Support/Yinghua/recordings/，仅你的 Mac 上的映话进程能访问。

唯一的例外是：如果你在 设置 → 转录 → 引擎 中选择"云端转录"，录音片段会通过 TLS 1.3 加密通道发送到云端转录服务（处理完成后立即删除）。这个选项默认关闭，且仅推荐在 Mac 性能不足以本地转录时使用。

完整数据流图与权限边界见 安全架构。

什么都不影响。映话的核心能力都是本地完成的：

  • 系统音频 + 麦克风录音 → 持续工作，写入本地
  • 本地转录（macOS 26 SpeechAnalyzer）→ 持续工作，文字立即显示
  • 说话人分离 → 持续工作
  • AI 总结 → 标记为"等待网络"，网络恢复后自动重试

所以你在飞机上、地铁里、酒店 WiFi 不稳时都可以放心使用映话。回到网络后再补做 AI 总结即可。

因为映话捕获的是系统音频（任何正在播放的音频）而不是某个特定 API，它支持所有会议平台：

  • Zoom（桌面版 / Web 版）
  • Microsoft Teams（桌面版 / Web 版）
  • Google Meet（Web 版，含 Chrome 扩展优化）
  • Cisco Webex
  • 腾讯会议、钉钉、飞书
  • Slack Huddles、Discord 语音
  • FaceTime、WhatsApp、Telegram 通话
  • 任何在 macOS 上播放音频的会议软件

如果你使用的平台没在列表里，大概率也能用 — 只要它的音频会从你的 Mac 扬声器或耳机出来。

AI 总结的质量取决于你使用的模型和会议内容。映话本身不做任何后处理 — 我们只把转录文本按 4 段结构（关键时刻、决定、待办、问题）发给 AI。

实测数据（100+ 早期用户，2026 年 7 月问卷）：

  • Anthropic Claude Sonnet 4.5：用户满意度 4.6 / 5，关键时刻召回率约 87%
  • OpenAI GPT-4o：用户满意度 4.4 / 5，待办识别较优
  • 本地 Ollama（Qwen 2.5 7B）：用户满意度 3.6 / 5，速度受限

请把 AI 总结当作"需要二次确认的草稿"，而不是权威记录。映话永远保留原始转录，你可以随时回看。

没有硬性限制。映话使用 48 kHz / 16-bit PCM 录制，1 小时立体声约 690 MB。

实测在 16 GB / 512 GB MacBook Pro 上：

  • 连续 8 小时录音不丢失帧（受 macOS Core Audio 内部 buffer 限制）
  • 磁盘空间允许的情况下无限时长
  • 默认 30 天自动清理，可在 设置 → 存储 中调整为 7 / 30 / 90 / 365 天 / 永久

录音过程中你可以随时暂停、继续、标记重要段落。

macOS 26 Tahoe 及以上 · Apple Silicon (M1 / M2 / M3 / M4) 或 Intel 14 代+。

具体要求：

  • macOS 26.0 或更高版本（macOS 26 SpeechAnalyzer 必需）
  • Apple Silicon M1 或更新（推荐）/ Intel Core i7 14 代或更新
  • 8 GB 内存（推荐 16 GB，本地 Ollama 7B 需要 16 GB+）
  • 5 GB 可用磁盘空间（应用本体）
  • 屏幕录制权限（捕获系统音频）
  • 麦克风权限（可选，仅当需要录入你的声音时）

Intel Mac 也能运行，但转录速度约为 M1 的 1/3。如果你的 Mac 不满足要求，请使用 v0.1.0 之前的 web 体验版（已归档）。

最多 8 人。基于声纹特征的本地分离模型，识别准确度：

  • 2-4 人：97% 标签稳定
  • 5-6 人：91% 标签稳定
  • 7-8 人：82% 标签稳定
  • 超过 8 人：仅显示通用标签，建议手动编辑

所有标签都可以在转录视图手动修正 — 选中一段文字、输入正确的说话人名称，映话会学习你的修正，未来类似声纹会自动匹配。

超过 8 人的场景（大型圆桌、研讨会、讲座）建议改用人工会议记录或分区录制。
