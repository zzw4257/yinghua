系统要求

macOS 26 Tahoe 或更高

需要 SwiftUI 6 + AppKit 互操作新 API。macOS 15 及更早版本不支持。

Apple Silicon 优先 · Intel 兼容

M1 / M2 / M3 / M4 完整性能。Intel Mac 可用但转录速度下降约 5x。

约 2 GB 磁盘空间

应用本体约 200 MB，首次启动下载 Whisper 中文模型 ~1.5 GB。模型可手动指定路径。

麦克风 + 屏幕录制权限

首次启动时会引导你授权。可在 系统设置 → 隐私与安全 中随时调整。

已知问题

  • Zoom 网页版（zoom.us/wc）在 Chrome 118 之前无法被系统音频捕获 — 升级 Chrome 即可。
  • 部分外接 USB 麦克风（特定型号）在 M1 Mac 上首次插入需重启映话。
  • 本地 Whisper 模型在大文件（> 4 GB）转录时占用较高 RAM（建议 16 GB+ 内存）。
  • 暂不支持 macOS 15 Sequoia — 我们使用 SwiftUI 6 新 API，不向下兼容。
安装步骤

三步开始使用。

01

下载 & 拖入

从 Mac App Store 或 GitHub Releases 下载映话，拖入 Applications 文件夹。

02

授权麦克风 & 屏幕录制

首次启动时按引导授权。可在 系统设置 → 隐私与安全 中随时调整。

03

（可选）配 BYOK

粘贴 Anthropic 或 OpenAI API Key，立即启用 AI 总结。不用 Key 也能用转录。
