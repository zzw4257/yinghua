隐私政策

我们没拿到的东西，
就不可能泄露。

本政策自 2026 年 8 月 22 日生效。最后更新：2026 年 8 月 22 日。

核心原则：映话不会收集你的录音、转录文本、AI 总结内容或 AI Key。 你的数据属于你。默认所有内容都存在你的 Mac 上，我们没有任何后端服务接收这些数据。

1. 我们不收集的信息

映话在默认设置下不会收集、上传或传输以下任何信息：

  • 你的会议录音或音频内容
  • 转录文本、说话人标签、关键词
  • AI 总结内容（关键时刻、决定、待办、问题）
  • 你的 Anthropic / OpenAI / 其他 AI 服务 API Key
  • 你的设备信息（型号、序列号、操作系统版本）
  • 你的使用统计、功能使用频率、会话时长
  • 崩溃日志（默认关闭，需手动启用）

2. 本地存储

映话将所有用户数据存储在 macOS 标准目录下：

  • 录音与转录：~/Library/Application Support/Yinghua/recordings/
  • 文本与索引：~/Library/Application Support/Yinghua/db.sqlite
  • 配置与 Key：macOS Keychain（系统级加密）

你可以随时访问、修改、导出或删除这些数据。卸载映话会同时删除所有数据。

3. 网络请求

映话仅在以下情况连接网络：

  • BYOK AI 调用：当你使用 Anthropic / OpenAI API 进行 AI 总结时，文本片段会发送到对应的 AI 提供商。这是 token 计费必要的请求，调用记录在你的 AI 账户后台。
  • iCloud 同步：当你启用 iCloud 端到端加密同步时，数据通过 Apple 的 E2EE 通道同步到你的其他 Apple 设备。映话无法解密这些数据。
  • 应用更新检查：映话每 24 小时向 updates.yinghua.zzw4257.cn 发送一次 GET 请求检查新版本（可关闭）。请求不包含任何用户数据。
  • 云端转录（可选）：如果你的 Mac 性能不足以本地转录，可以选择使用云端转录服务。音频片段会通过 TLS 加密通道发送，处理完成后立即删除。

4. AI Key 的存储

你提供的 API Key 始终加密存储在 macOS Keychain（系统级 Keychain 服务）中，映话进程以用户态访问，应用沙盒外的进程无法读取。Key 不会出现在：

  • 任何日志文件
  • 崩溃报告
  • 导出数据
  • 任何网络请求

5. 崩溃与诊断

映话默认不发送崩溃报告。你可以在 设置 → 隐私 → 发送匿名崩溃报告 中选择启用。启用后，仅发送：

  • 异常类型与堆栈跟踪（不包含你的数据）
  • 应用版本与 macOS 版本
  • 硬件型号（不包含序列号）

不会发送：录音路径、转录内容、文件名、Key 等任何用户数据。

6. 你的权利

你对自己的数据拥有完全控制权：

  • 访问：所有数据存储在你的 Mac 上，可以直接通过 Finder 或数据库客户端查看
  • 导出：一键导出 Markdown / SRT / JSON / 原始音频
  • 删除：删除单条录音、清空所有数据、卸载应用（自动删除全部）
  • 迁移：数据库文件可跨设备直接复制（不含 iCloud 同步）
  • 关闭同步：随时关闭 iCloud 同步，已同步的数据会保留在你的 iCloud 账户中（受 E2EE 保护）

7. 第三方服务

映话本身不向第三方出售、出租或分享你的数据。但当你使用 BYOK AI 总结时，文本片段会发送到你选择的 AI 提供商（Anthropic / OpenAI 等）。请阅读对应服务商的隐私政策：

  • Anthropic Privacy Policy
  • OpenAI Privacy Policy

8. 未成年人

映话不针对 16 岁以下用户。如果你是家长并发现未成年子女使用了映话，请联系 privacy@yinghua.app，我们会协助处理。

9. 政策变更

我们会在本页发布任何隐私政策的变更，并在映话应用内提示。重大变更（影响数据收集方式）会提前 30 天通知，并在下次启动时要求你重新同意。

11. 开源与可审计

映话的核心转录与加密模块在 GitHub 开源，任何人都可以审计代码、提交 issue、验证我们没有偷偷上传数据。

本政策基于 GDPR、CCPA、中国《个人信息保护法》 的要求编写。
