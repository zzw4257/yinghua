免费版每月可以转录 5 场会议（每场最长 60 分钟），所有数据完全存储在你的 Mac 上。你可以使用所有核心转录功能：实时文字、声纹分人、Markdown 导出等。AI 总结、跨设备同步和浏览器扩展需要 Pro 订阅。

BYOK = Bring Your Own Key（自备 API Key）。你提供自己的 Anthropic Claude 或 OpenAI API Key，映话用它调用 AI 总结。Key 存在 macOS Keychain，不会上传到我们的任何服务器。这样有几个好处：调用记录在你自己的 OpenAI/Anthropic 账户，合规、计费都更清晰，映话不接触你的数据。

1) 你主动选择"云端转录"（按次计费，可选）；
2) 你使用 BYOK 调用 AI API（按你账户的 token 计费）；
3) 你启用 iCloud 端到端加密同步（E2EE，映话无法解密）。

映话需要 macOS 26 Tahoe 或更高版本（因为使用了 SwiftUI 6 + AppKit 互操作的新 API）。Apple Silicon（M1/M2/M3/M4）和 Intel Mac 都支持，但 Apple Silicon 性能会显著更好。我们暂不支持 macOS 15 或更早版本。
