实时转录、AI 总结、本地优先、BYOK — 映话的每个功能都遵循同一个原则：数据属于你。

实时转录

讲到哪儿，
文字就跟到哪儿。

系统音频 + 麦克风双轨录入，毫秒级延迟输出文本。讲完一句，文字就定稿了。

  • 声纹分人 — 自动识别 2-8 个说话人，每个人的发言单独成段
  • 中文优化 — Whisper large-v3 中文模型 + 行业术语自定义词表
  • 离线运行 — 录音与转录全程在本地完成，无网络依赖
  • 时间码定位 — 点击文本任何一行，音频直接跳到对应位置
AI 总结

四类结构化输出，
会后立刻可用。

映话不写长篇"会议纪要" — 训练模型按照面试与会议的真实使用场景，输出四类内容。

  • 关键时刻 — 关键判断、技术难点、转折点的原文摘录
  • 决定事项 — 双方达成共识的具体结论，附原文上下文
  • 待办 — 带负责人、截止时间、需要跟进的具体动作
  • 遗留问题 — 没有结论、需要后续会议继续讨论的开放问题
本地优先

数据属于你，
不是某家云厂商。

映话的所有录音、转录、向量索引默认存在你的 Mac 上。我们不运营服务器，也不收集遥测。

  • 零遥测 — 没有分析脚本、没有崩溃上报、没有使用统计
  • SQLite + 本地向量 — 单文件存储，可以直接 Time Machine 备份
  • 端到端加密 — iCloud 同步采用 Apple E2EE 协议，我们无法解密
  • 导出 — 任何时刻导出 Markdown / SRT / JSON / 原始音频
BYOK · 自备 Key

用你自己的 AI Key，
或完全跑本地模型。

映话不内置 AI 模型。我们提供调用接口，但 token、计费、合规都掌握在你手里。

  • Anthropic Claude — Sonnet / Opus，按 token 计费
  • OpenAI — GPT-4o / GPT-5 系列，OpenAI 兼容 API
  • 本地 Ollama — Llama 3 / Qwen 2.5 / DeepSeek，零数据外传
  • Key 存储 — macOS Keychain 加密保存，不上传任何服务
隐私与安全

我们没拿到的东西，
就不可能泄露。

映话不会收集：

  • 你的录音内容（除非你主动选择上传分享）
  • 转录文本与 AI 总结
  • 你的 AI Key（仅存在 macOS Keychain）
  • 崩溃日志（默认关闭，可在设置中开启）
  • 设备信息、操作系统版本、安装路径

映话仅在以下情况连接网络：

  • 你选择启用云端转录（按次计费）
  • 你使用 BYOK 调用 Anthropic / OpenAI API
  • 你启用 iCloud 端到端加密同步
  • 应用内更新检查（可关闭）
