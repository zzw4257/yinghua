隅々にまで
抑制と信頼性を設計。

リアルタイム文字起こし、AI 要約、ローカル優先、BYOK — 映話のすべての機能が一つの原則に従います：データはあなたのものである。

リアルタイム文字起こし

話したその瞬間から、
テキストがついてくる。

システム音声 + マイクのデュアル録音、ミリ秒レベルの遅延でテキストを出力。話し終われば、テキストも確定します。

  • 声紋分離 — 2〜8 名の話者を自動認識し、発言ごとに独立したセグメントに
  • 日本語最適化 — Whisper large-v3 日本語モデル + 業界用語カスタム辞書
  • オフライン動作 — 録音と文字起こしはすべてローカルで完結、ネットワーク不要
  • タイムコードで位置指定 — テキストの任意の行をクリックすると、音声が該当位置にジャンプ
AI 要約

4 種類の構造化出力、
会議後すぐに使える。

映話は長文の「議事録」を書きません — 面接と会議の実利用シーンに合わせて訓練されたモデルが、4 種類の出力を生成します。

  • 重要な瞬間 — 重要な判断、技術的な难点、転換点となる原文の抜粋
  • 決定事項 — 双方の合意が成立した具体的な結論、原文のコンテキスト付き
  • ToDo — 担当者、期限、必要なフォローアップを含む具体的なアクション
  • 未解決の課題 — 結論に至らず、次の会議で議論すべきオープンな質問
ローカル優先

データはあなたのもの、
クラウドのものではない。

映話のすべての録音、文字起こし、ベクトルインデックスはデフォルトであなたの Mac に保存されます。サーバーを運営せず、telemetry も収集しません。

  • ゼロ telemetry — 分析スクリプトも、クラッシュレポートも、利用統計も一切なし
  • SQLite + ローカルベクトル — 単一ファイル保存、Time Machine で直接バックアップ可能
  • エンドツーエンド暗号化 — iCloud 同期は Apple E2EE プロトコルを使用、私たちにも復号不可
  • エクスポート — いつでも Markdown / SRT / JSON / 元の音声を書き出し
BYOK · 自分の Key

自分の AI Key を使う、
またはローカルモデルで完結。

映話は AI モデルを内蔵しません。呼び出しインターフェースは提供しますが、token、課金、コンプライアンスはあなたの手の中にあります。

  • Anthropic Claude — Sonnet / Opus、token 単位で課金
  • OpenAI — GPT-4o / GPT-5 シリーズ、OpenAI 互換 API
  • ローカル Ollama — Llama 3 / Qwen 2.5 / DeepSeek、データは外部送信ゼロ
  • Key の保存 — macOS Keychain に暗号化保存、どのサービスにもアップロードしない
プライバシーとセキュリティ

手にしていないものは、
漏れることもない。

映話は収集しません：

  • あなたの録音内容（あなたが能動的に共有を選んだ場合を除く）
  • 文字起こしテキストと AI 要約
  • あなたの AI Key（macOS Keychain にのみ保存）
  • クラッシュログ（デフォルトは無効、設定で有効化可能）
  • デバイス情報、OS バージョン、インストールパス

映話は次のケースでのみネットワークに接続します：

  • クラウド文字起こしを有効にした場合（従量課金）
  • BYOK で Anthropic / OpenAI API を呼び出す場合
  • iCloud エンドツーエンド暗号化同期を有効にした場合
  • アプリ内アップデートの確認（無効化可能）
