プライバシーポリシー

手にしていないものは、
漏れることもない。

本ポリシーは 2026 年 8 月 22 日に発効しました。最終更新日：2026 年 8 月 22 日。

基本原則：映話はあなたの録音、文字起こしテキスト、AI 要約の内容、AI Key を一切収集しません。 データはあなたのものです。デフォルトではすべてのコンテンツはご自身の Mac に保存され、これらデータを受信するバックエンドサービスは一切存在しません。

1. 収集しない情報

映話はデフォルト設定において、以下の情報を一切収集・アップロード・送信しません：

  • あなたの会議録音または音声コンテンツ
  • 文字起こしテキスト、話者ラベル、キーワード
  • AI 要約コンテンツ（重要な瞬間、決定、ToDo、課題）
  • あなたの Anthropic / OpenAI / その他 AI サービスの API Key
  • あなたのデバイス情報（モデル、シリアル番号、OS バージョン）
  • あなたの利用統計、機能使用頻度、セッション時間
  • クラッシュログ（デフォルトは無効、手動で有効化する必要あり）

2. ローカルストレージ

映話はすべてのユーザーデータを macOS の標準ディレクトリに保存します：

  • 録音と文字起こし：~/Library/Application Support/Yinghua/recordings/
  • テキストとインデックス：~/Library/Application Support/Yinghua/db.sqlite
  • 設定と Key：macOS Keychain（システムレベル暗号化）

これらのデータにはいつでもアクセス、変更、エクスポート、削除が可能です。映話をアンインストールすると、すべてのデータが同時に削除されます。

3. ネットワークリクエスト

映話は次のケースでのみネットワークに接続します：

  • BYOK AI 呼び出し：Anthropic / OpenAI API を使って AI 要約を行う際、テキストの断片が対応する AI プロバイダーに送信されます。これは token 課金に必要なリクエストであり、呼び出し記録はあなたの AI アカウントのバックエンドに残ります。
  • iCloud 同期：iCloud エンドツーエンド暗号化同期を有効にすると、データは Apple の E2EE チャネルを通じてあなたの他の Apple デバイスに同期されます。映話はこれらのデータを復号できません。
  • アプリアップデート確認：映話は 24 時間ごとに 1 回、updates.yinghua.zzw4257.cn に GET リクエストを送信して新バージョンを確認します（無効化可能）。リクエストにはユーザーデータは一切含まれません。
  • クラウド文字起こし（任意）：あなたの Mac の性能がローカル文字起こしに不十分な場合、クラウド文字起こしサービスを選択できます。音声の断片は TLS 暗号化チャネルで送信され、処理完了後すぐに削除されます。

4. AI Key の保存

あなたが提供する API Key は常に macOS Keychain（システムレベルの Keychain サービス）に暗号化保存され、映話のプロセスはユーザー権限でアクセスします。アプリのサンドボックス外のプロセスは読み取れません。Key は以下の場所には一切現れません：

  • すべてのログファイル
  • クラッシュレポート
  • エクスポートデータ
  • すべてのネットワークリクエスト

5. クラッシュと診断

映話はデフォルトではクラッシュレポートを送信しません。設定 → プライバシー → 匿名のクラッシュレポートを送信 で有効化を選択できます。有効化後、送信されるのは以下のみです：

  • 例外の種類とスタックトレース（あなたのデータは含まれません）
  • アプリバージョンと macOS バージョン
  • ハードウェアモデル（シリアル番号は含まれません）

録音パス、文字起こし内容、ファイル名、Key など、ユーザーデータは一切送信されません。

6. あなたの権利

あなたにはご自身のデータに対する完全なコントロール権があります：

  • アクセス：すべてのデータはご自身の Mac に保存されており、Finder やデータベースクライアントから直接閲覧可能
  • エクスポート：ワンクリックで Markdown / SRT / JSON / 元の音声を書き出し
  • 削除：1 件の録音を削除、すべてのデータをクリア、アプリアンインストールで自動全削除
  • 移行：データベースファイルは（iCloud 同期を介さず）デバイス間で直接コピー可能
  • 同期を停止：iCloud 同期はいつでも無効化可能、同期済みデータはご自身の iCloud アカウント内に残ります（E2EE で保護）

7. サードパーティサービス

映話自体はあなたのデータをサードパーティに販売・貸与・共有することはありません。ただし、BYOK AI 要約を使用する場合、テキストの断片はあなたが選択した AI プロバイダー（Anthropic / OpenAI など）に送信されます。各サービスのプライバシーポリシーをご確認ください：

  • Anthropic Privacy Policy
  • OpenAI Privacy Policy

8. 未成年者

映話は 16 歳未満のユーザーを対象としていません。保護者の方で、未成年の子供が映話を使用しているのを発見された場合は、privacy@yinghua.app までご連絡ください、対応いたします。

9. ポリシーの変更

プライバシーポリシーの変更はすべて本ページに掲載し、映話アプリ内でお知らせします。重大な変更（データ収集方法に影響するもの）は 30 日前に通知し、次回起動時に再同意を求めます。

11. オープンソースと監査可能性

映話の中核となる文字起こしと暗号化モジュールは GitHub でオープンソース公開されており、誰でもコードを監査し、issue を提出し、私たちが密かにデータを送信していないかを検証できます。

本ポリシーは GDPR、CCPA、中国「個人情報保護法」 の要件に沿って作成されています。
