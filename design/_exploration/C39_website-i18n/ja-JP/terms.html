シンプルなルール。

本規約は 2026 年 8 月 22 日に発効しました。最終更新日：2026 年 8 月 22 日。

本利用規約（以下「本規約」）は、Zhou Ziwei（以下「当社」）と、映話（Yinghua）アプリケーションおよびサービスを利用するあなた（以下「ユーザー」）との間で締結されます。映話をダウンロード、インストール、または使用することで、本規約に同意したものとみなされます。

1. サービス内容

映話は macOS 26+ ネイティブアプリケーションであり、以下の機能を提供します：

  • システム音声とマイクの録音
  • リアルタイム文字起こしと話者分離
  • AI 要約（ユーザー自身の API Key を使用）
  • ローカルストレージとエクスポート
  • 任意の iCloud エンドツーエンド暗号化同期
  • 任意の Chrome ブラウザ拡張（ウェブ会議用）

2. ライセンスと所有権

映話は以下のライセンスモデルを採用しています：

  • 無料版：コア文字起こし機能を永久無料で利用、支払い不要
  • Pro サブスクリプション：月払いまたは年払い、AI 要約、無制限文字起こし、デバイス間同期、ブラウザ拡張のアンロック
  • Team サブスクリプション：シート単位の課金、チーム协作、SSO、監査ログを追加

すべてのサブスクリプションは非独占的、譲渡不可の個人 / チーム利用ライセンスです。ソースコードの中核モジュールは MIT ライセンスでオープンソース公開、詳細は GitHub をご覧ください。

3. ユーザーの責任

映話を使用することで、あなたは以下の事項に同意します：

  • 合法的な使用：お住まいの司法管轄区域の法律（録音・録画の合法性に関する法律を含む）を遵守すること
  • 同意の取得：会議や会話を録音する前に、すべての参加者から明確な同意を得ること。司法管轄区域によっては「双方同意（two-party consent）」が必要となる場合があり、これは現地法に依存します
  • 悪用禁止：映話を以下の目的で使用しないこと：他人の秘密会話の盗聴、産業スパイ、ハラスメント、試験のカンニング、法的責任の回避など
  • アカウントセキュリティ：Mac ログイン認証情報、API Key、iCloud アカウントを適切に管理すること
  • AI Key のコンプライアンス：自身の API Key を使用する際は、対応するサービスプロバイダーの利用規約を遵守すること

4. プライバシー

映話のプライバシー慣行の詳細については、独立した プライバシーポリシー をご覧ください。基本的な約束：

  • あなたの録音、文字起こし、AI 要約の内容は当社のサーバーにアップロードされません
  • あなたの API Key は macOS Keychain にのみ保存されます
  • クラッシュレポート、telemetry、利用統計はデフォルトでは送信されません

5. サブスクリプションと請求

5.1 更新

macOS App Store 経由のサブスクリプションは、Apple が自動的に更新を処理し、サブスクリプション管理は App Store → アカウント設定にあります。サブスクリプションは解約するまで自動更新されます。

5.2 価格変更

当社は Pro / Team サブスクリプションの価格を調整する場合があります。変更は 30 日前に通知され、現在の請求期間内に支払い済みのサービスには影響しません。

5.3 解約

いつでもサブスクリプションを解約でき、解約後は現在の請求期間が終了するまではすべての有料機能を引き続きご利用いただけます。

6. 返金

  • App Store 購入：Apple ポリシーに従い、App Store → アカウント → サブスクリプション から返金を申請可能
  • 公式サイト購入：14 日以内であれば理由なしで返金、billing@yinghua.app までメールでご連絡ください
  • 教育版 / 非営利版：初回購入から 30 日以内であれば返金可能

過度な使用（例：50 回を超える会議の文字起こし、100 万 token を超える AI 要約の呼び出し）があった場合、返金額は実際の使用量に基づいて計算される場合があります。
