# 映话 Social Teaser — 5s 极简开场脚本

> **版本**：v1.0 · 2026-08-23
> **目标**：Twitter / X / Instagram Reels / TikTok 5s 视频开头
> **调性**：Apple Keynote 极简 · 一句话击中痛点 · 零堆词
> **总时长**：5.0s 精确到 0.1s · 30fps
> **画幅**：9:16（竖屏，1080×1920）+ 1:1（方版，1080×1080）+ 16:9（横版，1920×1080）三版本

---

## 0. 一句话

> 终于可以在 macOS 上，边开会、边记录了。

---

## 1. 制作总览

### 1.1 风格定位

| 维度 | 标准 |
|------|------|
| **调性** | Apple Keynote 极简开场（克制 / 安静 / 一句话击中）|
| **节奏** | 5s 3 段：暗场文字 → 文字完成 → logo 出现 |
| **音乐** | 0:00 ambient pad · 0:02 一次 heartbeat（低音脉冲）· 0:04 resolve chord |
| **字体** | 中文：Noto Serif SC 600（design-doc §2.2）· 英文：Inter Display 600 |
| **字号** | 标题 96pt（竖屏）/ 80pt（方版）/ 64pt（横版）|
| **品牌色** | 暖白 #F4F1EC（主文字）+ 紫 #B57BFF → 青 #2DD4BF 渐变（仅 logo）|
| **背景** | 暗色 #0A0A0F（design-doc §2.1 近黑）|
| **不使用** | ❌ 录屏 / ❌ 视频片段 / ❌ 滚动字幕 / ❌ emoji / ❌ 转场特效 |

### 1.2 投放渠道与画幅

| 渠道 | 画幅 | 比例 | 备注 |
|------|------|------|------|
| Twitter / X 视频 | 16:9 | 1920×1080 | 主版 |
| Instagram Reels | 9:16 | 1080×1920 | 竖屏 |
| TikTok | 9:16 | 1080×1920 | 竖屏 |
| Instagram Feed | 1:1 | 1080×1080 | 方版 |
| LinkedIn | 16:9 | 1920×1080 | 同 Twitter |
| YouTube Shorts | 9:16 | 1080×1920 | 竖屏 |

> **设计原则**：所有画幅共用同一脚本，仅文字位置和 logo 位置做适配（文字永远居中，logo 永远在文字下方 200px）。

## 2. 精确时间线（5.0s · 30fps）

### [0:00.0 - 0:02.0] 第 1 段 · 暗场文字逐字出现（2.0s）

| 项 | 内容 |
|----|------|
| 画面 | 全黑 #0A0A0F 背景，无任何元素 |
| 文字 | 暖白 96pt 标题行 **"终于可以在 macOS 上，"** |
| 动效 | 文字**逐字** fade-in（每个字 60ms 间隔，cubic-bezier(0.16, 1, 0.3, 1)）|
| 镜头 | 静止，无推拉 |
| 音乐 | 0:00 ambient pad 起（-12 LUFS）|
| 真实声 | 无 |

**逐字时序**（以 9 字符"终于可以在 macOS 上，"为例）：

```
0:00.0   暗场
0:00.0   "终"  fade-in 0-60ms
0:00.1   "于"  fade-in 60-120ms
0:00.2   "可"  fade-in 120-180ms
0:00.3   "以"  fade-in 180-240ms
0:00.4   "在"  fade-in 240-300ms
0:00.6   "macOS" fade-in 600-700ms
0:00.7   " "  fade-in 700-760ms
0:00.8   "上"  fade-in 800-860ms
0:00.9   "，"  fade-in 900-960ms
0:01.0 - 0:02.0  文字停留 1.0s（让观众读完）
```

> **总字数 9 个**，逐字出现时长 ≈ 1.0s，停留 1.0s。Apple 风格：让文字**呼吸**。

**End frame @ 0:02.0**：9 字暖白标题全亮，居中静止。

---

### [0:02.0 - 0:04.0] 第 2 段 · 文字完成（2.0s）

| 项 | 内容 |
|----|------|
| 画面 | 全黑 #0A0A0F 背景，标题行上移 40px |
| 文字 | 副标题 64pt 暖白 **"…边开会、边记录了。"** |
| 动效 | 标题上移 40px（300ms cubic-bezier(0.16, 1, 0.3, 1)）+ 副标题**整行** fade-in（600ms）|
| 镜头 | 静止，无推拉 |
| 音乐 | 0:02.0 一次 heartbeat（低音脉冲 -8 LUFS，0.4s）配合副标题出现 |
| 真实声 | 无 |

**End frame @ 0:04.0**：标题 + 副标题两行静止居中。完整文字：

> **终于可以在 macOS 上，**
> **…边开会、边记录了。**

---

### [0:04.0 - 0:05.0] 第 3 段 · Logo 出现（1.0s · 收尾）

| 项 | 内容 |
|----|------|
| 画面 | 全黑 #0A0A0F 背景，副标题淡出（fade-out 400ms） |
| 元素 | 副标题下方 200px 处，02 GRADIENT Y logo 1024 居中（width 240px）|
| 动效 | 副标题 fade-out 400ms + logo scale 0.92 → 1.0 + fade-in 600ms（spring cubic-bezier(0.16, 1, 0.3, 1)）|
| 镜头 | 静止 |
| 音乐 | 0:04.0 resolve chord（小三和弦，温暖收尾）+ 0:05.0 fade out |
| 真实声 | 0:04.5 一次 macOS bounce 提示声（轻）|

**资产引用**：
- Y logo 1024：`_exploration/C10_vector-icon/icon-02-gradient-1024__260823.png`
- 缩放后实际渲染：240×240px（竖屏）/ 200×200px（方版）/ 160×160px（横版）

**End frame @ 0:05.0**：logo 静止居中 → cut black 0.3s → 视频结束。

## 7. 验收 checklist

- [ ] 5s 总时长精确（±0.2s）
- [ ] 中文 / 英文 2 个版本都做
- [ ] 3 个画幅（16:9 / 1:1 / 9:16）都做
- [ ] 文字 ≤ 30 字（实际中文 18 字 / 英文 49 字符）
- [ ] 品牌色一致：暖白 #F4F1EC + 紫青渐变 + 近黑 #0A0A0F
- [ ] 逐字 fade-in 节奏舒适（60ms / 字）
- [ ] logo 用 02 GRADIENT（不要用 01 MINIMAL，teaser 要 brand impact）
- [ ] 不使用 emoji / 转场特效 / 录屏
- [ ] 静音版（无音乐）作为 fallback
