## 5. 录制指引（给录音师）

### 5.1 录音环境

- **录音棚**：干声棚（噪声 < -60 dBFS）
- **话筒**：大振膜电容（如 Neumann U87 / AKG C414）
- **话放**：高品质（无底噪）
- **监听**：录音师实时监听
- **背景**：无音乐 / 无其他声

### 5.2 表演指引

- **语气**：平静、专业、**不播音腔**（避免新闻联播感）
- **情绪**：克制（不是兴奋，不是热情）
- **节奏**：均匀，**不**像念诗，**不**像快读广告
- **重音**：仅在"映话" / "系统级" / "本地优先" / "AI" / "never" 等关键位置重读
- **停顿**：在句号 / dash "—" 处充分停顿（让画面切换有空间）

### 5.3 试录 3 条

1. **第 1 条**：平读，让配音员熟悉文案
2. **第 2 条**：强调关键数字（48 / 5 / 4）
3. **第 3 条**：最终版（综合 1+2 + 录音师建议）

### 5.4 不接受

- ❌ 任何"播音腔"（如央视新闻主持）
- ❌ 任何"销售腔"（如电话销售）
- ❌ 任何"AI 合成声"（用真人，不使用 ElevenLabs / Tortoise）
- ❌ 任何背景音乐 / 音效（干声，**无** reverb / 混响 / 压缩）
