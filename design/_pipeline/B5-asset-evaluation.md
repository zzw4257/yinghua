# B5 · 资产评估管线

> 用途：定义"什么算够好"——映话 (Yìnghuà) 的每一张图、每一个视频、每一条文案，按什么标准评估？谁评估？怎么 A/B？

## 评估 checklist（每张图）

| 维度 | 通过标准 | 失败兜底 |
|---|---|---|
| 调性匹配 | 主色在极光紫范围，底色近黑，玻璃质感清晰 | 重写 prompt；后期 Figma 调色 |
| 中文 UI 文字 | 中文渲染清晰，无错字 / 鬼画符 | 1) 改 prompt 强调"no text"；2) PS 加中文 |
| 玻璃质感 | 看得到半透明 + 模糊 + 边缘高光 | 改 prompt；或用 HTML 兜底 |
| 极光渐变 | 紫到浅紫可见，不是平涂 | 改 prompt 强调 "gradient" |
| 中文文案 | 文案无错别字，语调符合映话 voice | 重写文案 |
| 中文排版 | 字间距 / 行高合理，无重叠 | 重写 |
| 暗度 | 整体偏暗，不是亮色 UI | 改 prompt 强调"dark" |
| 隐喻 | 视觉概念能解释映话的功能（"映射对话"） | 重新设计 |
| 可发布感 | 看起来像真的产品，不是 mock | 重新生成；或退到 HTML prototype |

## 评估流程

1. **我**（agent）生成 5 个候选
2. **我**跑 checklist，对每个候选打 ✅ / ❌
3. **用户**看 5 个候选，挑 1-2 个
4. 选中的深挖到"可发布"质量
5. 没选中的入 archive（保留备查，但不当 final）

## A/B 比较方法

- 同主题出 5 个候选 → 用户在 5 个里挑 → 不用 A/B（一次出 5 个已经是 implicit A/B/C/D/E）
- 跨 round 收敛：每轮选中的"气质"叠加进下一轮 master prompt

## 谁评估

- **视觉调性**：用户（主） + 我（给 checklist）
- **中文文案**：用户（主） + 我（checklist）
- **功能正确性**：用户（主） + 我（checklist）
- **技术可实现性**：下一轮（实现 round）再评估

## "够好"的门槛

- ✅ 用户挑了 + 我 checklist 通过 + 3 个维度都"可发布" = 最终版
- ⚠️ 用户挑了 + 我 checklist 有 1-2 项 ⚠️ = 修一次，不行就重做
- ❌ 用户没挑 = 入 archive，不当 final

## 不在本规范内

- 视觉调性本身（design doc 收敛后定）
- 评估后的实现（下一 round）
